# SEO audit: agent playbook

Read **Operating rules** and **Repo map** before touching anything. Pick work by `status`. A task marked `NEEDS-*` must not be started without the missing input, which the entry names. **Section 9 is the list of things only a human can do.**

## 1. Operating rules

1. **Never push to `main`.** Every push to `main` deploys to production. Branch, open a PR, let Vercel build the preview.
2. **Never hand-edit generated output:** `work/*.html`, the card grid in `portfolio.html`, the rail in `index.html`, `sitemap.xml`. Edit `data/projects.json`, `templates/**` or `build.js`, run `node build.js`, commit the output.
3. **Never invent numbers, quotes, client names or results.** This site sells measured results. If a task needs a figure it is `NEEDS-CONTENT`: stop and ask.
4. **Headline stats are decided** (README "Content status", current as of main `a15d0f1`): 37K+ Instagram followers, 20+ trusted brands, ₹1 Cr+ revenue. Service pages also carry 38 sites shipped, "median mobile load under 1.8s" and ₹68 lakh tracked paid revenue, kept by decision. Make everything else agree; do not change them. (The project brief still says 60+ brands, 400+ trained, 32K+ followers: see SEO-11.)
5. **Canonical host is `https://kajalandani.co`** (`SITE` in `build.js`). It is not attached to the Vercel project yet. Do not "fix" canonicals to the vercel.app host.
6. **Do not re-introduce third-party font hosts, global `noindex`, or `<lastmod>` stamped from the build date.** `verify.py` fails on each.
7. Run `python3 -I .agents/seo-audit/verify.py` before every commit. It must print `all checks passed`.
8. Commit trailer for AI-authored commits: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

### SEO-02 · Staging host was indexable · APPLIED-UNVERIFIED
- **Evidence:** `robots.txt` on `kajalandanico.vercel.app` was `Allow: /`; no meta or header noindex; canonicals point at the not-yet-live `.co`.
- **Change:** `vercel.json` sends `X-Robots-Tag: noindex, nofollow` when the host matches `.*\.vercel\.app`. Host-scoped on purpose: a global noindex would deindex production the day `.co` is attached. `verify.py` fails if it ever loses the host condition.
- **Consequence:** until SEO-10 is done, nothing on this project is indexable. That is intended.
- **Accept (post-deploy, cannot be tested locally):** on the *production alias*, `curl -sI https://kajalandanico.vercel.app/ | grep -i x-robots-tag` returns the header; `curl -sI https://kajalandani.co/` returns none. (Vercel also adds noindex to preview URLs, so a preview check proves nothing.) If the deploy rejects the regex in `has.value`, replace it with the literal `kajalandanico.vercel.app`. The preview build itself succeeded, so the file parses.

## 7. Research: what search looks like for this site

**Method and limits.** SERPs were sampled with a web-search tool (US-based, not Google India or UK). It returns result titles and URLs only: no volumes, no difficulty. Treat every conclusion below as a hypothesis to validate in Search Console and Google Keyword Planner.

**Current-practice facts (cited):**
- Core Web Vitals "good" thresholds, at the 75th percentile: LCP 2.5 s or less, INP 200 ms or less, CLS 0.1 or less; INP replaced FID in 2024. [web.dev](https://web.dev/articles/vitals).
- Raptive's analysis of the March 2026 core update (rolled out 27 March to 8 April 2026) reports AI Overviews appearing more often and click-through 30-50% lower on searches that show one; and that sites with more thin pages (over 13% under 500 words) and slower pages were more likely to lose visibility. **This is a publisher network's correlation, not Google's statement**, drawn mostly from food and content sites. Use as a nudge, not a rule. [Raptive](https://raptive.com/blog/googles-march-2026-core-update/).

**What the SERPs showed.**
- *"Shopify SEO services for UK ecommerce stores agency"*: results were UK agencies plus directories (Semrush Agency Partners, DesignRush, Clutch).
- *"Meta ads real estate lead generation agency Delhi NCR"*: directories (DesignRush, Clutch, TechBehemoths) and marketplace gigs (Fiverr, Freelancer).
- *"local SEO taxi company airport transfer landing pages"*: how-to articles and marketplace gigs.
- *"Kajal Andani ..." and "kajalandani.co"*: none of her properties appeared in this tool. That is weak evidence (wrong engine, wrong region) but consistent with the domain not being live; **check her real brand SERP in Google and Search Console.**

**Implications.** Head terms ("SEO services", "website design agency") are held by directories and established agencies: do not target them. Directory profiles are where buyers and some links are. The achievable surface is brand queries plus narrow, proof-backed long-tail.

### PERF-04 · Loading screen on every page · P2 · NEEDS-DECISION
Every page opens with a full-screen white overlay (`z-index:10000`) that holds for at least 600 ms and until the `load` event, up to 5 s, with a 6 s CSS failsafe (`main.js` MIN 600 / MAX 5000).
- **Measured:** in the unthrottled trace homepage LCP completes at about 520 ms, of which **420 ms is "element render delay"**; the modeled LCP is 4.5-4.8 s. The overlay and `main.js` init are the likely cause; this audit did not isolate which.
- **Why it matters for SEO:** visitors arriving from search on a slow phone wait on a splash for every page view, including case-study landing pages. Google measures real-user LCP; the overlay does not exempt the page.
- **Options:** (a) keep as is; (b) show it only on the first page view per session (`sessionStorage`) and skip it on case-study pages; (c) remove it. Recommendation: (b). A design decision for the owner.
- **Accept:** field LCP (CrUX or Search Console) at or under 2.5 s at the 75th percentile after go-live.

Do not "fix" the line itself.

### PERF-06 / PERF-07 · CSS size and caching · P3 · NEEDS-DECISION
- `style.css` is 135 KB (about 31 KB gzipped; Vercel serves brotli) and render-blocking. Options: inline critical CSS per page, or split. Moderate effort, small gain; revisit only if field LCP is poor.
- CSS and JS have no explicit cache policy (Vercel default is revalidate every time, with ETag). Filenames are not hashed, so a long cache would serve stale CSS/JS with fresh HTML. Either hash filenames in `build.js` and then cache for a year, or leave it.

### A11Y-01 · Colour contrast · P3 · NEEDS-DECISION
Lighthouse `color-contrast` fails (WCAG AA 4.5:1 for normal text). Smallest changes that pass, computed:

| Where | Now | Ratio | Passing value |
| --- | --- | ---: | --- |
| `.badge` text `#894bfe` on `#141414` | `#894bfe` | 3.95 | `#9658ff` (4.51) |
| `--text-3` meta/eyebrow on white (`#8e8e86`) | `#8e8e86` | 3.30 | `#77776f` (4.51) |
| Muted text on dark (`#6d6d6d` on `#0b0b0b`) | `#6d6d6d` | 3.80 | `#797979` (4.52) |

These are brand tokens, so not applied. Accessibility is a quality signal, not a ranking factor.

### A11Y-02 · Carousel dots · P3 · NEEDS-DECISION
The three home rail dots (`aria-label="Go to slide n of 3"`) are below the minimum target size. Add padding to enlarge the hit area without changing the visible dot.

### SEO-19 · `.html` URLs · P3 · NEEDS-DECISION
`cleanUrls` is `false` by design. Extensionless URLs are cheapest before go-live and costly after. If chosen: `cleanUrls:true`, update `SITE`-derived URLs, canonicals, `og:url`, JSON-LD and internal links in one pass, and redirect the old `.html` URLs. Recommendation: leave as is; it costs nothing in rankings.

### SEO-20 · Empty `alt` · RESOLVED
Homepage has 16 `alt=""` images: the four hero covers, eight testimonial avatars, the three team avatars, and the preloader logo. All are decorative or sit beside a named quote, so empty `alt` is correct. Meaningful images have descriptive `alt` (the About graphic states its stats).
